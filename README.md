# 🏋️‍♂️ FitTracker - Your Ultimate Fitness Companion 
## Why FitTracker?

FitTracker is a modern, comprehensive fitness tracking app designed to help you conquer your health goals! Log your workouts, track nutrition, set goals, and connect with your community — all in one place.

---

## 🚀 Features at a Glance

- **💪 Workout Logging**: Track sets, reps, durations, and calories with ease.
- **🍎 Nutrition Tracker**: Manage meals, scan barcodes, and understand your macros.
- **🎯 Goal Setting**: Weight, calories, workouts — we keep you motivated!
- **👥 Social & Challenges**: Join challenges, connect with friends, and level up.
- **📈 Progress Insights**: Stunning analytics and charts to visualize your journey.

## ⚙️ Quick Setup (Run In 3 Easy Steps)

### Prerequisites

- Node.js (v14+ recommended)
- npm (comes with Node.js)
- MongoDB (local server or hosted)

Step 1: Clone this repo
git clone https://github.com/mdey26/Fitness-Tracker-App.git
cd Fitness-Tracker-App

Step 2: Install dependencies
npm install

### Configuration

Create a `.env` file in the root folder:
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000

Set these variables with your MongoDB URL and a strong JWT secret.

### Run the Dev Server
npm run dev

Navigate to `http://localhost:5000` and start exploring!
